# Lab 6: DOM & Event Handling (JavaScript)

Praktikum dasar manipulasi **DOM (Document Object Model)** dan **Event Handling** menggunakan HTML, CSS, dan JavaScript murni (_vanilla JavaScript_).

## 📁 Struktur File

- `index.html` — Struktur halaman web utama (berisi latihan DOM, form pendaftaran, dan daftar tugas).
- `style.css` — Berkas penataan gaya (_styling_) untuk elemen teks, _highlight_, dan daftar tugas.
- `script.js` — Logika JavaScript untuk interaksi, manipulasi elemen, dan validasi form.

## 🚀 Fitur Utama

1. **Manipulasi DOM Dasar**: Mengubah teks judul dan paragraf secara otomatis saat halaman dimuat.
2. **Event Click & Toggle Class**: Mengubah gaya teks (highlight & ukuran font) menggunakan fungsi kelas CSS _toggle_.
3. **Pencacah Karakter (Character Counter)**: Menghitung jumlah karakter pada input teks secara _real-time_.
4. **Validasi Form Pendaftaran**:
   - Memeriksa apakah nama sudah diisi.
   - Memvalidasi format email menggunakan _Regular Expression_ (`RegEx`).
   - Memastikan usia berupa angka bulat dengan rentang 17 sampai 100 tahun.
5. **Aplikasi Daftar Tugas (To-Do List)**:
   - Menambahkan tugas baru ke dalam daftar.
   - Menandai tugas sebagai selesai (_strikethrough_) atau membatalkannya kembali lewat tombol interaktif.

## 🛠️ Cara Menjalankan

1. Pastikan semua file (`index.html`, `style.css`, dan `script.js`) berada dalam satu folder yang sama.
2. Buka file `index.html` menggunakan browser pilihan kamu (Chrome, Firefox, Edge, dll.).
3. Atau, gunakan ekstensi **Live Server** di Visual Studio Code untuk pengalaman _live-reload_.
